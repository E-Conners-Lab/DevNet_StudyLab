# Direct dependencies for the DevNet StudyLab lab engine.
#
# Versions are pinned exactly so a rebuild produces the same image months from
# now. `requirements.lock.txt` holds the fully resolved tree (direct plus
# transitive) and is what the Dockerfile installs; this file is the
# human-editable list of what the service actually imports.
#
# To upgrade: change a pin here, then regenerate the lock from a CLEAN base
# image - never from the lab-engine image, which already has the old lock
# installed, so a removed dependency would never leave the lock:
#
#   docker run --rm -v "$PWD/services/lab-engine:/src:ro" python:3.12-slim \
#     sh -c 'pip install -q -r /src/requirements.txt 1>&2 \
#            && pip list --format=freeze --exclude pip' \
#     | sort > services/lab-engine/requirements.lock.txt
#   # then restore the header comment at the top of the lock file
#
# `pip install -q` writes to stderr (1>&2) so no stray line lands in the lock.
# `pip list --format=freeze` is used over `pip freeze` because the latter omits
# setuptools/wheel, which a package can rely on at runtime; `--exclude pip`
# keeps the installer itself out of the tree it installs.
#
# scripts/check-lock-drift.sh asserts these pins match the lock; CI runs it.
# Last resolved: 2026-09-27
